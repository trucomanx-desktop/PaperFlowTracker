# paper-flow-tracker

Follow each stage of the process of publishing scientific articles

![logo](https://raw.githubusercontent.com/trucomanx-desktop/PaperFlowTracker/main/screenshot.png)

## 1. Installing

To install the package from [PyPI](https://pypi.org/project/paper_flow_tracker/), follow the instructions below:


### With pip

```bash
pip install --upgrade paper_flow_tracker
```

Execute `which paper-flow-tracker` to see where it was installed, probably in `/home/USERNAME/.local/bin/paper-flow-tracker`.

### With pipx (recommended for desktop applications)

```bash
pipx install paper_flow_tracker
```

If you need to upgrade later: `pipx upgrade paper_flow_tracker`

### Using

To start, use the command below:

```bash
paper-flow-tracker
```
