# paper-flow-tracker

Follow each stage of the process of publishing scientific articles


## Install from PYPI

The homepage in pipy is https://pypi.org/project/paper_flow_tracker/

```bash
pip install --upgrade paper_flow_tracker
```

or (recommended for desktop applications)

```bash
pipx install paper_flow_tracker
```


Using:

```bash
paper-flow-tracker
```

## Install from source
Installing `paper-flow-tracker` program

```bash
git clone https://github.com/trucomanx-desktop/PaperFlowTracker.git
cd PaperFlowTracker
pip install -r requirements.txt
cd src
python -m build
pip install dist/paper_flow_tracker-*.tar.gz
```
Using:

```bash
paper-flow-tracker
```

## Uninstall

```bash
pip uninstall paper_flow_tracker
```
